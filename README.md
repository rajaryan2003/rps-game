# Rock Paper Scissors 🎮✊📄✂️

A simple and interactive **Rock Paper Scissors** game built with **HTML, CSS, and JavaScript**.  
Play against the computer and test your luck!

---

## 🚀 Features
- 🎯 Choose Rock, Paper, or Scissors  
- 🤖 Computer generates a random move  
- 🏆 Displays the winner of each round  
- 🎨 Styled with CSS for a clean UI  
- ⚡ Built with pure JavaScript (no frameworks)  

---

## 🛠️ Tech Stack
- **HTML5** – structure  
- **CSS3** – styling and layout  
- **JavaScript (ES6)** – game logic  

---

## 📂 Project Structure
📦 rock-paper-scissors
┣ 📜 index.html
┣ 📜 style.css
┗ 📜 script.js


---

## ▶️ How to Play
1. Open the game in your browser.  
2. Select **Rock**, **Paper**, or **Scissors**.  
3. The computer will randomly pick its choice.  
4. The result (Win/Lose/Draw) will be displayed.
